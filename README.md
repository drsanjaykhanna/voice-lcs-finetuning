# Fine-tuning versus prompting for voice-appropriate clinical communication in lung cancer screening

Materials accompanying the manuscript of the same title, which is currently under review.

## The study in brief

A 2 x 3 factorial simulation study of language models for telephone-style clinical communication in NHS lung cancer screening.

- **Models:** a fine-tuned Gemma 2 9B, the unmodified Gemma 2 9B-IT, and Gemini 2.5 Flash.
- **Prompting conditions:** a neutral clinical system prompt, and the same prompt with explicit voice-delivery rules.
- **Conversations:** 100 simulated patient scenarios in each of the six cells (600 conversations).
- **Evaluation:** automated text metrics, language-model judges, blinded human raters, and clinician-adjudicated fact verification.
